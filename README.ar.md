## عن سراج

**سراج** تطبيق قرآن عربي يعمل على Android وWindows وLinux. يجمع المصحف والتلاوات والتفسير والبحث ومعاني الكلمات والتجويد والحفظ والورد والختمة والأذكار والعلامات والإحصاءات في تجربة واحدة متجاوبة تحترم العربية وواجهة RTL.

صُمم المشروع على مبادئ واضحة:

- **النص أولًا:** واجهة قراءة هادئة، وفهرس لا يزاحم صفحة المصحف، وتنقل مباشر إلى الموضع المطلوب.
- **المصدر معلوم:** البيانات والأصول الخارجية مرتبطة بسجلات منشأ وإصدارات وبصمات.
- **الخصوصية افتراضيًا:** لا يحتاج سراج إلى حساب، وتبقى بيانات القراءة الأساسية على جهاز المستخدم.
- **التحديث لا يسبق التحقق:** لا يُعلن إصدار مستقر إلا بعد الاختبارات والتوقيع والبصمات وبوابة الإصدار.
- **لا ادعاء زائد:** التحقق الآلي من البنية والمنشأ لا يُقدّم بوصفه اعتمادًا علميًا بشريًا.

> الاسم المعروض هو **«سراج — قرآن كريم»**. أما `com.quran.mushaf` فهو معرّف حزمة Android تاريخي أُبقي حتى تظل الترقية من الإصدارات السابقة ممكنة.

- مصحف كامل من **6,236 آية** و**114 سورة**.

- فهرس للسور والأجزاء والآيات، مع انتقال مباشر وحفظ آخر موضع.
- حفص بالرسم العثماني، وحفص بالنص الإملائي المبسط، وعرض ملوّن لأحكام التجويد مع شرح الحكم عند الضغط؛ تبقى هذه الخيارات مستقلة عن مسار التعلم ولا تُزال بسببه.
- تبويب مستقل لتعلم التجويد بثلاث مراحل لكل حكم: فهم القاعدة، وتمييزها من المثال، ثم تطبيقها، مع خطة تكيفية تقدّم المواضع الأضعف والمراجعات المستحقة وتستخدم التكرار المتباعد محليًا.
- مستويات كثافة اختيارية، وقياس إتقان، ومجموعات تحتاج تثبيتًا، وأسئلة تمييز وملخص للجلسة؛ ولا تُخلط بيانات رواية أو طريق أو وجه بغيرها.
- روايات إضافية تشمل ورشًا وقالون والدوري إلى جانب حفص، مع حجب منهج التعلم الخاص بها حتى يتوفر مصدر مستقل ومراجعة علمية مناسبة بدل استخدام منهج حفص بديلًا.
- عرض حفص واسع: عنوان السورة والبسملة في المنتصف، ونص متصل، وعلامات آيات زخرفية.
- معالجة البسملة في طبقة العرض كي تظهر مرة واحدة دون تغيير ملف المصدر أو الترقيم أو ربط الصوت والتفسير.
- تحديد النص ونسخه، ونسخ الآية مع مرجعها، والمشاركة حيث تدعم المنصة ذلك.
- علامات محفوظة وتظليل دائم بألوان متعددة والرجوع السريع إلى المواضع.
- تنقل مقصود يمنع تقليب الصفحة العرضي عند التمرير الرأسي أو استخدام لوحة اللمس.

## سلامة التحديث وسلسلة التوريد

### Android

- APK Release كامل وموقّع.
- تحقق من استمرار شهادة الموقّع وارتفاع `versionCode`.
- تحقق من الحجم وSHA-256 قبل عرض التثبيت.
- تضمين الأصول المحلية المطلوبة داخل APK والتحقق منها آليًا.

### Windows وLinux

- قناة تحديث مستقلة لكل منصة وموقعة بـ **Ed25519**.
- تحقق من المنتج والإصدار والحجم وSHA-256 قبل التطبيق.
- ترقيعات `.sirajpatch` تحمل توقيعًا وبيانًا ببصمة كل ملف.
- محاكاة تثبيت الترقيع فوق الحزمة الكاملة `4.1.1` داخل بوابة الإصدار.
- تبقى بيانات المستخدم خارج نطاق الاستبدال، مع مسار رجوع عند فشل التحديث.

### أدلة الإصدار

- CycloneDX SBOM لحزم سطح المكتب.
- GitHub build provenance/attestations للأصول المرشحة.
- تحقق من مجموعة الأصول الدقيقة قبل الترقية من Draft إلى Release.
- GitHub Immutable Releases وإبقاء الإصدار السابق بدل حذفه.
- مفاتيح التوقيع الخاصة محفوظة في GitHub Secrets ولا تدخل المستودع.

> ملفات Windows التنفيذية لا تحمل توقيع Authenticode حاليًا؛ لذلك قد يعرض SmartScreen تحذيرًا. حماية مسار التحديث تعتمد على Ed25519 والبصمة والحجم والإصدار المقفل.

## متطلبات المنصات والتثبيت

### Android

- Android 5.1 (API 22) أو أحدث.
- نزّل APK من [الإصدار الرسمي](https://github.com/mosalah30688-gif/quran/releases/tag/siraj-android-v1.4.4).
- تحقق من البصمة إن رغبت، ثم اسمح بالتثبيت من المصدر الذي استخدمته.
- الترقية تحفظ معرّف الحزمة التاريخي نفسه وشهادة التوقيع نفسها.

> تجهيز Google Play مؤجل؛ الإصدار المعتمد حاليًا هو APK المباشر من GitHub.

### Windows

- Windows 10 إصدار 1809 أو أحدث، أو Windows 11، بنية x64.
- نزّل [Portable 4.1.1 الكامل](https://github.com/mosalah30688-gif/quran/releases/tag/siraj-windows-v4.1.1)، وفك ZIP كاملًا، ثم شغّل `Siraj.exe`.
- لا يحتاج إلى مثبّت أو صلاحية مدير.
- يحفظ بيانات النسخة المحمولة في `UserData` بجوار البرنامج ولا يستخدم Registry للإعدادات.
- حدّث من داخل التطبيق إلى `4.1.4` أو استخدم الترقيع الرسمي وفق واجهة التحديث.

### Linux

- Linux x86_64 بواجهة سطح مكتب حديثة.
- نزّل [AppImage 4.1.1 الكامل](https://github.com/mosalah30688-gif/quran/releases/tag/siraj-linux-test-v4.1.1).
- امنحه صلاحية التنفيذ مرة واحدة:

```bash
chmod +x Siraj-Quran-4.1.1-linux-x86_64.AppImage
./Siraj-Quran-4.1.1-linux-x86_64.AppImage
```

- يتولى التطبيق بعد ذلك الوصول إلى قناة الترقيع المستقرة الموقعة حتى `4.1.3`.
- لا يوزع المشروع DEB أو RPM أو مثبّتًا بصلاحيات مدير.
