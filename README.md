# سراج — قرآن كريم

تطبيق قرآن متعدد المنصات يضم قراءة المصحف والروايات والتلاوات والتفسير والبحث ومعاني الكلمات والتجويد والحفظ والورد والأذكار والعلامات والإحصاءات.

## المنصات

### Android

المشروع الحالي مبني بـ Capacitor داخل:

- `android/`
- `app.js` و`index.html`
- `www/`

بناء الويب والمزامنة:

```bash
npm ci
npm run android:sync
```

### Windows — الخطة الجديدة

مسار مستقل حديث داخل `windows_app/`، واسمه الرسمي:

- **سراج**
- الوصف: **قرآن كريم**
- الإصدار الأول: `1.0.0`
- Windows 10/11 x64

النواتج:

- مثبّت Inno Setup حديث per-user.
- نسخة Portable حقيقية تحفظ بياناتها بجوار البرنامج.
- تحديث مرتبط بـ GitHub Releases مع توقيع Manifest عبر Ed25519 وفحص الحجم وSHA-256.
- توقيع Authenticode إلزامي للإصدارات المستقرة.

راجع [`windows_app/README.md`](windows_app/README.md) للتشغيل والبناء والتفاصيل.

### Linux السابق

نسخة Qt/AppImage السابقة باقية مؤقتًا داخل `mushaf_app/`، وخط بنائها منفصل عن Windows الجديد.

## خصائص Windows الجديدة

- واجهة عربية RTL متجاوبة وشريط تنقل يضغط تلقائيًا.
- فهرس سورة/جزء/آية منسدل لا يستهلك مساحة الصفحة.
- Amiri Quran افتراضيًا، مع Amiri وNoto Naskh Arabic وScheherazade New وخطوط Windows المناسبة.
- تحديد النص والنسخ، ونسخ الآية مع المرجع، وتظليل آيات دائم.
- سطر مصحف متقارب دون فراغات مبالغ فيها.
- البسملة تحت عنوان السورة، مع الحفاظ على ترقيم المصدر المختار وربطه بالتلاوة والتفسير.
- جميع خصائص Android الأساسية موجودة في مسار Windows.

## مصادر المحتوى

يعتمد المشروع حاليًا على ملفات محلية وعلى خدمات مثل:

- `api.alquran.cloud`
- `everyayah.com`
- `cdn.mp3quran.net`
- `quranpedia.net`

قبل الإصدار المستقر العام يجب استكمال توثيق الرخص والمصادر والمراجعة العلمية. راجع [`windows_app/THIRD_PARTY_NOTICES.md`](windows_app/THIRD_PARTY_NOTICES.md).
