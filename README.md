# سراج — قرآن كريم

تطبيق قرآن متعدد المنصات يضم قراءة المصحف والروايات والتلاوات والتفسير والبحث ومعاني الكلمات والتجويد والحفظ والورد والأذكار والعلامات والإحصاءات.

## المنصات

### Android

المشروع الحالي مبني بـ Capacitor داخل:

- `android/`
- `app.js` و`index.html`
- `www/`

إصدار Android الحالي في المصدر هو `1.4.0` (`versionCode 140`). يتضمن المصحف المحلي لحفص والتجويد وفهرس السور وأربعة خطوط OFL، ويتكيف مع الهاتف والتابلت والوضعين الرأسي والأفقي. حزمة التفاسير الـ78 منفصلة عن APK: ينزّلها المستخدم اختياريًا إلى مساحة التطبيق، ويتحقق Android من الحجم وSHA-256 وبنية SQLite قبل اعتمادها.

بناء الويب والمزامنة:

```bash
npm ci
npm run android:sync
```

يبني workflow ‏`.github/workflows/android.yml` ملف Release موقّعًا فقط، ويقارن شهادة توقيعه بشهادة `update/app.apk` الحالية ويتحقق أن `versionCode` أعلى قبل النشر. عند تشغيله يدويًا مع `publish=true` ينشر APK و`SHA256SUMS.txt` ثم يحدّث قناة `update/manifest.json`. مفتاح Android يأتي من GitHub Secrets ولا يُحفظ في المستودع.

### Windows — الخطة الجديدة

مسار مستقل حديث داخل `windows_app/`، واسمه الرسمي:

- **سراج**
- الوصف: **قرآن كريم**
- الإصدار التالي المخطط (لم يُبنَ بعد): `4.1.1`
- Windows 10/11 x64

الناتج:

- نسخة Windows Portable فقط؛ تُفك بالكامل ويُشغّل `Siraj.exe` بلا تثبيت أو صلاحية مدير.
- تحفظ بياناتها في `UserData` بجوار البرنامج ولا تستخدم Registry للإعدادات.
- تحديث مرتبط بـ GitHub Releases مع توقيع Manifest عبر Ed25519 وفحص الحجم وSHA-256.
- لا يُستخدم Authenticode؛ تُنشر النسخة Portable بلا مثبت مع SHA-256 وSBOM وattestation، وقد يعرض Windows تحذير SmartScreen المعتاد للملف غير الموقّع.
- `4.1.1` حزمة كاملة بسبب دمج بيانات التفاسير؛ التحديثات العادية التالية حزم `.sirajpatch` صغيرة موقعة، والحزمة الكاملة للتحديث الرئيسي أو تغيير runtime/dependencies الأصلية.

راجع [`windows_app/README.md`](windows_app/README.md) للتشغيل والبناء والتفاصيل.

### Linux — AppImage

مسار Linux داخل `mushaf_app/` يحمل الهوية نفسها **سراج — قرآن كريم** وينتج:

- `Siraj-Quran-4.1.1-linux-x86_64.AppImage`
- `Siraj-Quran-4.1.1-linux-corresponding-source.zip`
- `SHA256SUMS.txt`
- `SBOM.cdx.json`

يبني GitHub Actions الحزمة على Ubuntu 22.04، ثم يشغّل اختبارات الواجهة والبيانات والتلاوة من داخل AppImage، ويشغّل التطبيق بلا arguments تحت X11 افتراضي ويتحقق من ظهور نافذة «سراج» قبل رفع artifact باسم `siraj-linux-appimage`.

يتضمن الإصدار `4.1.1` قاعدة تفسير محلية مضغوطة: 73 كتابًا تراثيًا مختارًا من ملفات Quranpedia الرسمية و5 طبعات مدققة من AlQuran Cloud (78 خيارًا)، لذلك تعمل النصوص دون إنترنت ويكبر حجم الحزمة الكاملة.

بعد التنزيل يلزم منح الملف صلاحية التنفيذ مرة واحدة من **Properties → Permissions → Allow executing file as program** أو بالأمر:

```bash
chmod +x Siraj-Quran-4.1.1-linux-x86_64.AppImage
./Siraj-Quran-4.1.1-linux-x86_64.AppImage
```

لا يُنشئ هذا المسار حزمة DEB/RPM أو مثبّتًا. نُشر إصدار `4.1.1` بعد اجتياز بوابة مراجعة التراخيص والبيانات؛ ولا يجوز للإصدارات اللاحقة تجاوز البوابة نفسها.

## خصائص Windows الجديدة

- واجهة عربية RTL متجاوبة وشريط تنقل يضغط تلقائيًا.
- فهرس سورة/جزء/آية منسدل لا يستهلك مساحة الصفحة.
- Amiri Quran افتراضيًا، مع Amiri وNoto Naskh Arabic وScheherazade New وخطوط Windows المناسبة.
- تحديد النص والنسخ، ونسخ الآية مع المرجع، وتظليل آيات دائم.
- عرض حفص واسع بأسلوب الشاملة: عنوان وبسملة في المنتصف، فقرة متصلة، أسطر متقاربة، وعلامات آيات زخرفية؛ عدد الأسطر يتجاوب مع عرض النافذة.
- البسملة تظهر مرة واحدة تحت عنوان السورة؛ تُفصل للعرض من أول آية حفص عند وجودها مدمجة، مع بقاء نص المصدر وترقيمه وربط التلاوة والتفسير دون تغيير.
- جميع خصائص Android الأساسية موجودة في مسار Windows.
