# القرآن الكريم - تطبيق ويب تقدمي (PWA)

تطبيق قرآن يعمل من المتصفح على الهاتف والحاسوب، ويمكن تثبيته كتطبيق.

## المميزات الحالية (النسخة الأولى)
- **السور**: قائمة بالسور الـ 114 مع بحث بالاسم أو الرقم.
- **القراءة**: عرض الآيات بعدة رسوم (عثماني، إملائي، مختصر، ملوّن بأحكام التجويد).
- **التلاوة**: تشغيل السورة كاملة أو آية بآية مع 16 قارئاً، وتمييز الآية الجارية.
- **التفسير**: 6 كتب تفسير، عرضها بجانب كل آية أو في لوحة منفصلة.
- **الترجمة**: عدة لغات تُعرض تحت الآية.
- **الحفظ**: تحديد مقطع، إخفاء النص وإظهاره بالضغط، وتكرار التلاوة عدداً محدداً من المرات.
- **العلامات وآخر قراءة**: حفظ الآيات المفضلة والعودة لآخر موضع.
- **الوضع الليلي**، وتكبير الخط، والعمل بدون اتصال للواجهة.

## المصادر
- النص والتلاوات والتفاسير: `api.alquran.cloud` (وملفات الصوت من `cdn.islamic.network`).

## تشغيل محلي
```bash
cd quran
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`.

## خطة التطوير
- روايات إضافية (ورش، قالون، الدوري...) تحتاج مصدر نص منفصل.
- تجويد تفاعلي مع شرح كل حكم وأمثلة صوتية.
- وضع الاختبار للحفظ.
- التغليف كتطبيق أصلي: أندرويد (APK/AAB)، iOS، ويندوز، ماك، لينكس.
