# محرك سراج للسياق والعادات المحلية

هذه الوثيقة تصف عقد نواة السياق ودمجها المحلي في واجهة سراج. منطق القرار العام في `smart-context.js`، وتحويل خدمات سراج إلى مرشحين في `smart-services.js`، والربط المرئي في `app.js`. الاختبارات مستقلة داخل `tests/`.

## مبادئ ملزمة

1. **محلي أولًا:** لا يرسل المحرك أحداثًا أو ملفات عادات إلى أي خادم.
2. **موافقة صريحة:** القيمة الافتراضية `enabled: false`، ولا يتخذ المحرك قرار تدخل قبل تفعيل المستخدم له.
3. **أقل قدر من البيانات:** يقبل المحرك قائمة ثابتة من أنواع الأحداث وحقول السياق؛ الروابط، النصوص الحرة، والمفاتيح غير المعروفة تُحذف.
4. **احتفاظ محدود:** المدة الافتراضية 35 يومًا، والحد المسموح من 7 إلى 90 يومًا.
5. **منع الإزعاج قبل الترتيب:** النوم المحتمل، وقت الهدوء، الحد اليومي، وفترة التهدئة بوابات قطعية تسبق أي خوارزمية تعلم.
6. **قابلية التفسير:** يعيد كل قرار أسبابه ودرجات مكوناته، ولا يعرض نتيجة غامضة للمستخدم.
7. **فشل آمن:** المدخل غير الصحيح يُرفض، والمرشح غير المكتمل لا ينتج عنه تدخل.

## الأحداث المقبولة

- نشاط التطبيق والجهاز: `APP_OPEN`, `APP_FOREGROUND`, `DEVICE_ACTIVE`, `SCREEN_ON`, `SCREEN_OFF`.
- الخدمات والقراءة والاستماع: `SERVICE_OPEN`, `SERVICE_COMPLETE`, `READ_PAGE`, `READING_SESSION_END`, `PLAY_RECITATION`.
- الحفظ والتجويد: `START_MEMORIZATION`, `COMPLETE_MEMORIZATION`, `OPEN_TAFSIR`, `OPEN_TAJWEED`, `COMPLETE_TAJWEED_LESSON`, `TAJWEED_ANSWER`.
- دورة حياة الإشعار: `NOTIFICATION_SHOWN`, `NOTIFICATION_OPEN`, `NOTIFICATION_COMPLETE`, `NOTIFICATION_SNOOZE`, `NOTIFICATION_NOT_NOW`, `NOTIFICATION_DISMISS`.
- دورة حياة البطاقة داخل التطبيق: الأنواع المناظرة التي تبدأ بـ`SUGGESTION_`، حتى لا تُسجّل البطاقة على أنها إشعار نظام.

لا تُقبل أحداث عامة مثل سجل التصفح، ولا نصوص المستخدم أو محتوى الحافظة. حقول السياق محصورة في مؤشرات تشغيلية قصيرة مثل رقم الصفحة، الرواية، فئة الخدمة، قاعدة التجويد، المصدر الداخلي، العدد، مدة الجلسة، ومعرّف الاقتراح.

## نموذج العادة

- يُقسّم اليوم إلى 48 نافذة، مدة كل منها 30 دقيقة.
- لكل خدمة ملف زمني مستقل؛ لا تُخلط عادة الورد بعادة الأذكار أو التجويد.
- وزن الحدث يتناقص أُسّيًا، بنصف عمر افتراضي 14 يومًا.
- تُنعّم النافذة الحالية بنافذتيها المجاورتين حتى لا تتغير النتيجة عند حدود النصف ساعة.
- لا يوصف الملف بأنه «متعلّم» قبل بلوغ الحد الأدنى للعينات، وهو 7 افتراضيًا.

## تقدير النوم والاستيقاظ

يستخرج المحرك أول نشاط وآخر نشاط لكل يوم مكتمل نسبيًا، ثم يستخدم الوسيط بدل المتوسط لتقليل أثر الأيام الشاذة. تُقدّر بداية النوم بعد آخر نشاط بنصف ساعة، مع مجال آمن، وتبقى الثقة مرتبطة بعدد الأيام المتاحة.

عند عدم وجود تاريخ، يستخدم المحرك افتراضًا محافظًا (23:00 إلى 07:00)، وتبقى ساعات الهدوء بوابة مستقلة. إشارة نشاط الشاشة الآنية يمكن أن تثبت أن المستخدم مستيقظ، لكنها لا تتجاوز ساعات الهدوء التي اختارها.

## ترتيب المرشحين

بعد المرور من بوابات الأمان، تحسب الدرجة من مكونات قابلة للفحص:

- ملاءمة الوقت مع العادة المحلية.
- الاستحقاق والحاجة.
- استعداد السياق الحالي.
- الاستجابة التاريخية.
- استكشاف محلي محدود بأسلوب Contextual UCB.
- الاستمرارية، الصلة، والأولوية.

يُخصم من الدرجة عند انخفاض الاستعداد. وعند تساوي الدرجات يكون كسر التعادل ثابتًا بمعرّف المرشح، لتكون الاختبارات والقرارات قابلة لإعادة الإنتاج.

## بوابات الأمان

تُطبق بالترتيب الآتي:

1. المحرك غير مفعّل أو المرشح معطّل.
2. نوم محتمل.
3. ساعات الهدوء.
4. بلوغ الحد اليومي.
5. عدم انتهاء فترة التهدئة بعد آخر اقتراح.
6. إنجاز الخدمة في اليوم نفسه.
7. عدم مطابقة الحالة السياقية أو النافذة الزمنية.
8. الدرجة دون الحد الأدنى.

لا يجوز لأي درجة تعلم أو أولوية أن تتجاوز البوابات من 1 إلى 7.

## واجهة البرمجة

يصدر الملف كائن `SirajSmartContext` في المتصفح، ويدعم CommonJS لاختبارات Node. الواجهة الأساسية:

```js
const engine = new SirajSmartContext.SmartContextEngine(savedState);
engine.configure({ enabled: true });
engine.record({ type: 'READ_PAGE', service: 'wird', context: { page: 42 } });
const decision = engine.evaluate(candidates, deviceSignals);
const stateForLocalStorage = engine.snapshot();
```

عند عرض اقتراح يجب استدعاء `markShown`، ثم تسجيل `feedback` عند الفتح أو الرفض أو التأجيل. الوسيط الرابع/الثالث `suggestion` يميز بطاقة التطبيق عن إشعار النظام. لا يرسل المحرك إشعارًا بنفسه؛ هو ينتج قرارًا فقط، وتبقى طبقة الواجهة وAndroid مسؤولة عن العرض والجدولة.

## دمج خدمات سراج

تسجل الواجهة، بعد التفعيل فقط، فتح التطبيق والجلسة والقراءة والتلاوة والأذكار والحفظ والتفسير والتجويد. لا تسجل نص الآية أو الذكر أو البحث. ينشئ `smart-services.js` مرشحين للورد وأذكار الاستيقاظ والصباح والمساء والمراجعات المستحقة، ولا يقترح التلاوة أو التجويد استكشافيًا قبل استخدامهما فعليًا.

تظهر النتيجة كبطاقة داخل المحتوى لا كنافذة تغطي القراءة، وبها: تنفيذ، تأجيل، إخفاء، وشرح «لماذا ظهر؟». تعرض الإعدادات التفعيل الصريح، ساعات الهدوء، الحد اليومي، التهدئة، مدة الاحتفاظ، وعدد الأحداث المحلية، مع زر مستقل لمسح سجل العادات دون حذف بيانات المصحف.

## جسر Android الاختياري

يظهر خيار مستقل لإشعارات Android الذكية؛ لا تُطلب الصلاحية عند تفعيل التعلم المحلي، بل عند تشغيل هذا الخيار وحده. يقرأ الجسر إشارات تشغيل غير حساسة: تفاعل الشاشة، قفل الجهاز، توفير الطاقة، الشحن، ونسبة البطارية. لا يطلب موقعًا أو جهات اتصال أو ميكروفونًا أو صلاحية وصول.

تخطط JavaScript أقرب قرار آمن خلال 30 ساعة بنوافذ نصف ساعة، ثم ترسل مرشحًا واحدًا فقط إلى منبه Android غير الدقيق. يعيد مستقبل Android فحص نافذتي الهدوء والنوم لحظة التنفيذ؛ إن كان الوقت محظورًا يؤجل بدل العرض. تُطبق البوابة نفسها على تذكير الورد الثابت عندما يكون المحرك مفعّلًا.

يسجل Android محليًا `shown/open/snooze/dismiss` بحد أقصى 32 نتيجة معلقة، ثم يستهلكها المحرك عند فتح التطبيق. نقر الإشعار يفتح وجهة الخدمة، و«لاحقًا» يؤجل ساعتين، والحذف لا يجدول بديلًا تلقائيًا. لا يعمل منبه ذكي دوري مستقل عن فتح سراج؛ كل خطة لقطة واحدة يعاد بناؤها بعد مزامنة الحالة المحلية.

## الدمج والبناء

- يُحمّل `smart-context.js` ثم `smart-services.js` قبل `app.js` في الحزمة المحلية وترقيعات الواجهة.
- ينسخهما `scripts/build-www.sh` إلى `www/`، ويثبتهما Service Worker ضمن shell cache.
- يضمهما ناشر تحديثات الواجهة وAndroid في أي قناة مستقبلية.
- يتحقق CI من البنية والاختبارات ووجود الملفين داخل APK.

## الاختبارات

يشغّل الأمر التالي مجموعة الاختبارات الحتمية:

```bash
npm run test:smart
```

تغطي الاختبارات تنقية الخصوصية، الاحتفاظ، الاضمحلال، تعلم النوافذ، تقدير النوم، بوابات المنع، البداية الباردة، التغذية الراجعة، مرشحي الخدمات، عناصر الموافقة والشرح، الحفظ وإعادة الضبط، والفشل الآمن.

## خارج نطاق هذا الدمج

لا تجمع طبقة Android موقعًا أو محتوى شاشة أو سجل تطبيقات، ولا تعمل خدمة مراقبة دائمة في الخلفية. كما أن تعلم التجويد المتباعد وبيانات كل رواية/طريق مشروعان مستقلان عن اقتراحات الخدمات العامة.
