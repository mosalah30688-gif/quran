# إدخال مصادر التجويد المستقلة ومراجعتها

## المبدأ

لا يتحول توفر نص رواية أو مولد آلي إلى طبقة تجويد منشورة. تمر كل حزمة مستقلة عبر خمس بوابات منفصلة:

1. **هوية النطاق:** الرواية والطريق والوجه والطبعة محددة بلا قيم عامة مضللة.
2. **الحقوق:** ترخيص المصدر الأصلي وحق إعادة توزيع corpus والنتائج المشتقة مثبتان كتابةً.
3. **الربط النصي:** كل إزاحة مربوطة بايتًا وبـUnicode code points إلى طبعة ثابتة ذات SHA-256.
4. **المراجعة العلمية:** مراجع مؤهل في الرواية والطريق يفحص القواعد والأمثلة والعلامات ويسجل مادة المراجعة ببصمتها.
5. **اعتماد النشر:** شخص ثانٍ يطابق دليل الحقوق والمراجعة والبصمات قبل تغيير الحالة إلى `APPROVED`.

الفشل في أي بوابة يبقي المحتوى خارج `tajweed-curricula/` وخارج أصول التطبيق.

## نتيجة فحص مرشح ورش من طريق الأزرق

عُثر على حزمة حديثة مولدة بواسطة `quranic-phonemizer 3.0.5` ومعلنة لورش عن نافع من طريق الأزرق. ثُبتت الحزمة التالية دون نسخها إلى المشروع:

- الإصدار: `warsh-tajweed-v1`.
- SHA-256: `0898c80ad1325a36031a24f45a2ca6c1649c051c94e88de89cc594c70273b4f8`.
- الحجم: `2,642,177` بايت.
- 604 صفحات، و6,214 آية فريدة، و46 معرف حكم.
- 164,141 مقطع علامة و212,214 إسناد حكم.
- لا توجد أخطاء في بصمات نصوص الحزمة أو حدود المقاطع.

أعيد الفحص محليًا بالأمر:

```bash
python3 scripts/analyze_warsh_tajweed_candidate.py \
  /path/to/warsh-tajweed-v1.zip \
  --output /tmp/warsh-analysis.json
```

التقرير المقفول في:

```text
audit/tajweed-candidates/warsh-al-azraq-qud-v1.analysis.json
```

لا يحتوي التقرير نص القرآن أو العلامات نفسها؛ يحفظ القياسات والبصمات والموانع فقط.

## لماذا لم تُنشر حزمة ورش؟

رغم اكتمالها التقني، فشلت بوابة النشر للأسباب الآتية:

- يصرح سجل مصدر المولد بأن corpus ورش الأصلي أضيف بلا تسجيل رابط upstream أو ترخيصه.
- الحزمة نفسها تصف العلامات بأنها **مرشح تقني وليست تزكية دينية**، وتطلب مقارنتها بمصحف تجويد معتمد ومراجعة شيخ مؤهل في ورش.
- تطابقت 5,250 آية فقط بايتًا مع نص ورش الحالي في سراج. وبعد NFC وإزالة علامة الحزب والتطويل بقيت 250 آية مختلفة نصيًا، ولذلك لا يجوز نقل الإزاحات تلقائيًا.
- اختلف تعيين الصفحة في 58 آية بين الطبعتين.
- الوجه الناتج من إعدادات المولد لم يُثبت أو يُراجع علميًا، ولم يسجل اعتماد شخص ثانٍ.

لذلك حالتها:

```text
QUARANTINED_NOT_PUBLISHABLE
```

ولا تظهر للمستخدم ولا تطبق بدلًا من طبعة ورش الحالية.

## قالون والدوري

- **قالون:** يتوفر دليل تعليمي رسمي محتمل من الهيئة العامة للأوقاف والشؤون الإسلامية في ليبيا، لكن لا توجد حزمة علامات حرفية كاملة، ولا ترخيص corpus، ولا تثبيت للطريق والوجه والطبعة وربطها بنص سراج.
- **الدوري عن أبي عمرو:** يتوفر النص المحلي وبعض المراجع الببليوغرافية للأصول، ولا توجد حزمة تجويد حرفية شاملة مرخصة أو مراجعة مرتبطة بالطبعة.

وجود المراجع النظرية لا يسوغ استخراج نصوصها آليًا أو تحويلها إلى اعتماد علمي.

## ملف التسليم المطلوب من صاحب المصدر

لكل نطاق يجب تسليم:

- اسم الرواية والطريق والوجه والطبعة ورقمها أو رابطها الرسمي.
- corpus الأحكام والعلامات بترميز Unicode وإزاحات نصف مفتوحة `[start, end)`.
- بصمة النص الذي حُسبت عليه الإزاحات، ووحدة القياس والتطبيع.
- قائمة الأحكام وشرحها وألوانها ومراجع صفحات المصدر.
- دليل ترخيص يغطي إعادة الاستخدام والتوزيع داخل سراج.
- اسم المراجع المؤهل وصفته وتاريخ المراجعة ودليلها.
- بصمة مادة المراجعة، واسم معتمد النشر الثاني.

ثم تُحوّل الحزمة إلى عقد `tajweed-curriculum.schema.json` ويشغل:

```bash
python3 scripts/verify_tajweed_scopes.py
python3 scripts/verify_tajweed_source_candidates.py
npm run test:smart
```
