# حزم التجويد المستقلة

هذا المجلد مخصص لحزم التجويد التي اجتازت بوابة المصادر والمراجعة. لا يحتوي حاليًا أي حزمة منشورة؛ وجود نص رواية في التطبيق لا يعني وجود طبقة تجويد موثقة لها.

## وحدة الفصل

كل ملف JSON يمثل نطاقًا واحدًا فقط بالمفتاح الكامل:

```text
riwayah / tariq / wajh / edition
```

لا يجوز أن تتشارك الحزم التقدم أو الأحكام أو العلامات، ولا يجوز الرجوع إلى حزمة حفص عند غياب حزمة رواية أخرى. يسمح سجل `tajweed-scope-registry.json` بأكثر من حزمة للرواية نفسها عند اختلاف الطريق أو الوجه أو الطبعة.

## عقد الحزمة

يجب أن يطابق كل ملف `tajweed-curriculum.schema.json`. وهو يفصل بين:

1. **النص القرآني الثابت:** ملف مستقل مقفول ببصمة SHA-256 ومحدد باسم مجموعة البيانات.
2. **هوية العرض:** الاسم العربي للرواية والطريق والوجه والطبعة، وتدخل هذه الهوية في بصمة المراجعة.
3. **الأحكام التعليمية:** الاسم والشرح التفصيلي واللون ومراجع المصدر.
4. **العلامات:** مقاطع نصف مفتوحة `[start, end)` محسوبة بوحدات Unicode code points، وتشير إلى النص الثابت بدل نسخه أو تغييره.
5. **المصادر:** لقطة مؤرخة وبصمة ورابط ودليل ترخيص لكل مصدر.
6. **المراجعة:** اسم المراجع المؤهل وصفته وتاريخ المراجعة وبصمة المحتوى الذي راجعه، ثم اعتماد نشر من شخص ثانٍ.

## مسار الإدخال

1. تثبيت الرواية والطريق والوجه والطبعة نصًا في السجل.
2. حفظ لقطات المصدر ودليل الترخيص وبصماتها داخل `audit/sources/`.
3. إدخال الأحكام والعلامات من المصدر المصرح به دون استنتاج آلي منشور بوصفه معتمدًا.
4. تشغيل:

   ```bash
   python3 scripts/verify_tajweed_scopes.py
   python3 scripts/verify_tajweed_source_candidates.py
   npm run test:smart
   ```

5. تسليم الحزمة إلى مراجع بشري مؤهل. تحسب بصمة مادة المراجعة من الحقول `scope`, `display`, `textBinding`, `sources`, `rules`, `annotations` بترميز JSON حتمي (مفاتيح مرتبة، دون مسافات).
6. بعد المراجعة فقط: ضبط `status` و`review.status` إلى `APPROVED`، وإضافة المراجع والاعتماد الثاني والدليل، وربط الحزمة بالسجل مع بصمة ملفها.
7. إعادة التحقق والاختبارات والمراجعة اليدوية للعرض والألوان والأمثلة قبل النشر.

## التحميل والتحديث المحلي

يقرأ `tajweed-curriculum-loader.js` المؤشرات من السجل، ولا يفتح حزمة إلا بعد تطابق مسار artifact والبصمة والحالة والنطاق الكامل وبصمة طبعة النص. يعيد فحص جميع حدود Unicode ومراجع الأحكام في الجهاز، ولا يختار تلقائيًا بين طريقين أو وجهين صالحين؛ تعرض الإعدادات التسميات العربية المراجعة وتطلب اختيار النطاق الكامل عند التعدد. لا يلون صفحة المصحف إلا بحزمة `APPROVED` ومفعلة للنشر؛ يدعم العارض تداخل الأحكام ويحافظ على تسلسل code points بعد التطبيع المعلن في الحزمة، وتعرض العلامة عند الضغط شرح أحكامها من الحزمة نفسها.

ينسخ `scripts/build-www.sh` الحزم المعتمدة إلى Android/PWA. أما ترقيات الواجهة فتضع JSON في IndexedDB بدل `localStorage` لتفادي حد الحجم، وتتحقق من SHA-256 قبل تفعيل الإصدار. يجهز `scripts/publish-update.sh` قائمة الملفات وبصماتها تلقائيًا، ويخزن Service Worker الحزم المشار إليها للاستخدام دون اتصال.

أي حزمة ناقصة أو متغيرة بعد المراجعة تفشل مغلقًا. لا تُنشئ أداة التحقق أحكامًا ولا تمنح اعتمادًا علميًا.
