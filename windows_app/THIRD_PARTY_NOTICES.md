# إشعارات المصادر والمكونات الخارجية

ترخيص MIT في جذر المستودع يخص **الكود الأصلي فقط**. لا يعيد ترخيص نصوص القرآن أو التفاسير أو الترجمات أو الصوتيات أو الخطوط أو البيانات والأصول الخارجية المذكورة أدناه.

## الخطوط

الخطوط التالية مضمّنة وفق **SIL Open Font License 1.1**، ونسخ التراخيص موجودة داخل `windows_app/fonts/`:

- Amiri Quran
- Amiri
- Noto Naskh Arabic
- Noto Sans Arabic
- Scheherazade New

## مكتبات التطبيق

- PySide6 / Qt for Python
- miniaudio
- cffi
- PyNaCl / libsodium (التحقق من توقيع Ed25519 لقناة التحديث)
- PyInstaller (أداة بناء الحزمة المحمولة)

تظل تراخيص كل مكوّن سارية وفق حزمته الأصلية. ينشئ مسار Windows ملف `SBOM.cdx.json` بصيغة CycloneDX لكل بناء؛ وتبقى مراجعة تراخيص المكتبات والملفات الفعلية شرطًا قبل النشر النهائي.

## بيانات ومصادر المحتوى الحالية

وفق الكود والوثائق الموجودة في المستودع وقت إعادة البناء:

- النصوص، مصحف `quran-tajweed` الملوّن، وبعض التفاسير والترجمات: `api.alquran.cloud`
- التلاوات: `everyayah.com` و`cdn.mp3quran.net`
- بعض بيانات المعاني: موثقة في الواجهة باسم `quranpedia.net`

**مطلوب قبل الإصدار المستقر:** توثيق مصدر كل ملف JSON ورخصة إعادة توزيعه، ومراجعة النصوص والروايات مراجعة علمية مستقلة. لا يُعد الاختبار البرمجي اعتمادًا شرعيًا أو علميًا للنص.
